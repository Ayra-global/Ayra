# Guía de contribución

## Ramas
- `main`: producción, integración. Todos los PR apuntan aquí.
- Ramas de trabajo desde `main`: `feature/nombre`, `fix/nombre`, `chore/nombre`.

## Commits
Formato: `tipo: descripción corta`. Tipos: `feat`, `fix`, `chore`, `docs`.

## Pull requests
1. Abre el PR hacia `main` con la plantilla completa.
2. Agrega labels (`sprint-1` y el área) y enlaza el issue con `Closes #N`.
3. Necesita 1 aprobación y que el CI pase.
4. No apruebes tu propio PR.
